# zao-2026

2026 蔵王の集い 参加者向けサイト（GitHub Pages ＋ GAS）。

- このリポジトリには参加者データを置かない。データは合言葉付きで GAS から取得する
- 合言葉はコード・リポジトリに書かない（GAS のスクリプトプロパティ `PASSPHRASE` のみ）

## ファイル

| ファイル | 内容 |
|---|---|
| `index.html` | サイト本体（HTML/CSS/JS。ビルド不要） |
| `config.js` | `GAS_URL` と `MOCK` 切り替えのみ |
| `mock.json` | MOCK モード用のダミーデータ（実在の人の名前は入れない） |
| `robots.txt` | 検索エンジンを全面拒否 |
| `gas/Code.gs` | GAS コードの控え（実際はスプレッドシートの Apps Script に貼る） |

## 動作確認（MOCK モード）

```sh
python3 -m http.server 8000
# → http://localhost:8000/?mock=1  を開き、合言葉に「test」と入力
```

- `?mock=1` を付けると `mock.json` を読む（`config.js` の `MOCK: true` でも同じ）。MOCK の合言葉は `test`、それ以外は「合言葉が違います」になる
- `&now=2026-10-10T13:45` を付けると「今日・今の時刻」を差し替えられる（タブの自動選択・「いま」の強調の確認用）
- MOCK と本番は端末内の保存データが別々なので混ざらない

## シートを更新したとき

- スプレッドシートの「公開_」シートを書き換えると、最大60秒でサイトに反映される（参加者はページ下の「最新の情報に更新」か再読み込み）
- すぐ反映させたいとき：Apps Script エディタで関数 `clearCache` を実行

## 合言葉の変え方

1. Apps Script →「プロジェクトの設定 → スクリプト プロパティ」で `PASSPHRASE` を書き換える（再デプロイ不要）
2. LINE グループで新しい合言葉を知らせる
   - 古い合言葉を保存している端末は、次回アクセス時に「合言葉が変更されました」と入力画面に戻る

## GAS のコードを直したとき

「デプロイ → デプロイを管理 → 編集 → バージョン：新バージョン」で、同じ URL のまま更新する。`gas/Code.gs` の控えも合わせて更新する。

## イベント終了後の片付け（10/18 目安）

1. Apps Script →「デプロイを管理」→ ウェブアプリのデプロイを**アーカイブ**（以後データは一切返らない）
2. GitHub → Settings → Pages → 公開を停止（Source を「None」に）。必要ならリポジトリを Private にする
3. 参加者には「この端末から合言葉を削除」ボタンで端末内のデータを消せることを案内してもよい
